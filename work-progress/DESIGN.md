# 엔티티 프레임 작업 화면 디자인 계약

## 1. 방향

호메로스 위키의 학술 작업 과정을 보여주는 단일 문서형 화면이다. 장식보다 정보 위계, 근거 구분, 한국어 가독성을 우선한다.

## 2. 색상

- `--paper`: 따뜻한 종이색 배경
- `--ink`: 본문 잉크색
- `--muted`: 보조 설명색
- `--line`: 구획선
- `--accent`: 현재 단계와 핵심 판단
- `--panel`: 카드 표면

## 3. 서체

- 본문과 제목: Georgia, Noto Serif KR, serif
- 메타데이터: system-ui, Noto Sans KR, sans-serif
- 본문 최소 크기: 16px

## 4. 간격과 레이아웃

- 4px 배수 간격 체계
- 본문 최대 너비 1120px
- 모바일 1열, 760px 이상에서 요약 카드 2열
- 긴 한국어 제목은 단어 단위로 자연스럽게 줄바꿈

## 5. 구성 요소

- 상태 표식: 완료, 진행 중, 예정의 텍스트 상태
- 판단 카드: 조사 결과와 설계 결론을 한 항목씩 표시
- 프레임 표: 공통 코어와 선택 모듈의 구분
- 단계 목록: 작업 순서와 현재 위치 표시

## 6. 상호작용과 움직임

정적 작업 기록 화면이므로 동작과 장식 애니메이션을 사용하지 않는다.

## 7. 깊이

테두리와 미세한 표면색 차이만 사용한다. 그림자는 사용하지 않는다.

## 8. 접근성 및 수용 부채

- WCAG 2.2 AA 수준 명도 대비를 목표로 한다.
- 의미는 색상만으로 전달하지 않고 텍스트 상태를 병기한다.
- 키보드 상호작용이 필요한 요소는 없다.
- 수용한 접근성 부채 없음.
