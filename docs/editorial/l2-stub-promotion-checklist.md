# L2 stub promotion checklist

Use with `docs/editorial/outline-contract.md` (P0 experimental).

On the **first** commit that expands an L1 stub:

- [ ] H2 titles match the type template L2 list (bilingual, verbatim)
- [ ] Replaced `증거 메모` / stub etymology memo with Evidence Matrix section title
- [ ] Concept §2 ≤5 lines and links `[[word-*]]` (etymology SoT)
- [ ] Entity includes `## 서사적 입구 (Narrative Entry)` when required (person/deity/place)
- [ ] `npm run check:ci` passes
- [ ] Related-item / index links updated both ways if new hubs were promoted
