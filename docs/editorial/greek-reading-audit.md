# 그리스어 읽기 UX 감사 기준선

## 기준선의 지위

이 문서는 그리스어 읽기 UX 구현 시작 시점의 작업 기준선이다. 수치는 승인된 구현 계획에 보존된 2026-08-26 스냅숏에서 옮긴 잠정값이며, 아직 구현되지 않은 인벤토리 스크립트가 계산한 최종 감사 결과가 아니다. 따라서 이 문서의 수치는 완료율, 엄격 검증 통과, 또는 코퍼스의 확정 상태를 주장하지 않는다.

재현 가능한 최종 기준선은 후속 단계에서 `scripts/greek-reading-inventory.mjs --report`를 같은 공개 범위에 실행하여 생성한다. 그 결과는 실행 시각, Git 기준점, 범위 규칙, 제외 경로, 스크립트 버전과 함께 이 문서를 갱신해 대체한다. 이 문서는 그 전까지 규모와 우선순위를 보존하는 시작점이다.

## 공개 범위와 집계 원칙

최종 인벤토리는 다음 범위를 구분해 보고해야 한다.

- `index.md`
- Quartz 제외 경로가 아닌 `wiki/**/*.md`
- `words/**/*.md`
- `wiki/log.md`는 집계하되 공개 본문 마이그레이션 대상에서는 제외
- `wiki/meta/**`는 내부 문서로 별도 보고
- `_template.md`는 템플릿 범주로 별도 보고
- YAML frontmatter, 일반 산문, 표, Mermaid·코드 펜스, 인용 후보, 제목·링크 별칭을 구분

그리스 문자 탐지는 Greek Extended와 결합부호를 포함해야 하며, 비교 키는 Unicode NFC를 사용한다. 단순한 기본 그리스 문자 범위만으로는 폴리토닉 문자를 빠뜨릴 수 있다.

## 계획 스냅숏의 잠정 수치

아래 값은 구현 계획의 추정 스냅숏이다. 인벤토리 구현 전에는 새로 계산하거나 최종값으로 표기하지 않는다.

| 항목 | 잠정값 | 해석 |
|:---|:---|:---|
| `wiki/`와 `words/`의 Markdown 문서 | 48개 | 집계 대상 규모의 계획 시점 추정치 |
| 그리스 문자를 포함한 문서 | 35개 | 공개·내부·템플릿 구분 전의 전체 추정치 |
| 연속 그리스어 문자열 | 약 1,410개 | 문자열 단위의 계획 시점 추정치 |
| NFC 정규화 고유 문자열 | 약 626개 | 정규화 뒤의 고유형 추정치 |
| 그리스어 포함 행 | 약 534개 | 행 단위 검토량의 추정치 |
| `wiki/log.md` 제외 공개 후보 | 약 1,297개 문자열, 34개 문서 | 단계적 이행 규모의 추정치 |
| IPA형 표기 | 2개 단어 문서의 8개 사례, `wiki/`에는 없음 | IPA는 이번 범위에서 추가·표준화하지 않는다는 확인점 |

고밀도 문서의 계획 시점 예시는 다음과 같다.

| 파일 | 잠정 그리스어 문자열 수 | 감사상 의미 |
|:---|---:|:---|
| `words/word-odyssey.md` | 약 260개 | 대형 형태론 표와 실제형·표제형 구분을 포함한다. |
| `wiki/analyses/analysis-polytropos.md` | 약 125개 | 고밀도 분석 문서의 후속 이행 후보이다. |
| `wiki/sources/scott-1981-some-greek-terms.md` | 약 115개 | 장문 그리스어 인용이 있어 파일럿에 포함된다. |
| `wiki/concepts/concept-nemesis.md` | 약 98개 | 고밀도 개념 문서의 후속 이행 후보이다. |

## 도구 구현 후 실측 기준선

2026-08-26 고정 파일럿 마이그레이션과 legacy 원장 갱신 후 `node scripts/greek-reading-inventory.mjs --report`를 실행한 결과다. 이 수치는 계획 스냅숏을 대체하는 현재 입력의 재현 가능한 기준선이며, 다음 배치 변경 후에는 같은 명령으로 다시 갱신한다.

| 항목 | 실측값 |
|:---|---:|
| 전체 Markdown 문서 | 52 |
| 그리스 문자를 포함한 문서 | 38 |
| public 그리스어 포함 문서 | 36 |
| 그리스어 run | 1,700 |
| NFC 비교 고유 run | 682 |
| public 그리스어 run | 1,582 |
| public NFC 비교 고유 run | 666 |
| NFC 위반 run | 0 |
| 집계된 그리스어 행 | 648 |
| public 그리스어 행 | 613 |

범주별 run은 `codeFence 32`, `frontmatter 68`, `heading 32`, `prose 907`, `quotation 278`, `table 383`이다. 문서 범위는 `internal 1`, `log 1`, `public 47`, `template 3`이며, 제목 그리스어 run은 4개, 구형 삼중 제목 후보는 12개, 링크 별칭 그리스어 run은 8개다. 실행 시 legacy 유예는 31개, 전사 예외 원장은 `approved 0 / review 0 / rejected 0`이었다.

`집계된 그리스어 행`과 `public 그리스어 행`은 보고서의 문서별 `greekLines`를 각각 전체·public 범위에서 합산한 값이다.

## 기존 표기 변이의 관찰

계획 스냅숏은 다음과 같은 혼용을 확인했다. 이것은 오류 목록이나 자동 치환 목록이 아니라 `homeric-oriented-v1`에서 표준 출력과 검색 호환값을 분리해야 하는 이유를 보이는 사례다.

| 관찰된 변이 | 감사상 처리 방향 |
|:---|:---|
| `Aidôs`, `Aidōs`, `Aidos` | 화면 표준은 규약에 따라 하나로 정하고, 필요한 기존형은 aliases 또는 매핑으로 보존한다. |
| `Mênis`, `Menis` | 표제형·악센트·장모음 근거를 검토한 뒤 화면 표준을 적용한다. 미확정값은 확정 표기로 쓰지 않는다. |
| `Achilles`, `Achilleus` | 관용 라틴명과 학술 전사를 별도 필드로 관리한다. |
| `podas ōkus`, `podas ôkus` | 실제형·장단·악센트의 근거를 확인하고, 기계적 혼용을 없앤다. |

## 고정 파일럿

파일럿은 다음 네 파일로 고정한다. 이 목록은 현재 파일별 최종 측정값이나 이행 완료를 뜻하지 않는다.

1. `wiki/concepts/concept-aidos.md`
2. `wiki/entities/entity-achilles.md`
3. `words/word-odyssey.md`
4. `wiki/sources/scott-1981-some-greek-terms.md`

| 파일 | 선정 이유 | 이행에서 확인할 계약 |
|:---|:---|:---|
| `concept-aidos.md` | 본문 삼중 표기와 용어 변형이 많다. | 첫 완전 공개 뒤 반복 표기를 축소한다. |
| `entity-achilles.md` | 관용 영어명, 학술 전사, 정형구 표가 함께 있다. | 관용명과 전사 분리, 표의 별도 전사 열을 검증한다. |
| `word-odyssey.md` | 제목 예외, 어원 변이, 실제형·표제형, Mermaid, 대형 형태론 표가 있다. | 단어 페이지 제목 예외와 실제형 대응을 검증한다. |
| `scott-1981-some-greek-terms.md` | 여러 용어와 긴 그리스어 인용이 있다. | 번역·원문·실제형 전사의 행 단위 구조를 검증한다. |

## 재현 절차와 갱신 조건

후속 인벤토리 도구가 추가된 뒤 다음 절차로 기준선을 재생성한다.

1. 실행 전 `git status --short`와 `git diff --stat`를 기록하여 사용자 변경과 인벤토리 결과를 구분한다.
2. `npm run check`의 결과를 기록한다. 기존 실패가 있으면 그리스어 읽기 작업과의 관련성을 구분한다.
3. `scripts/greek-reading-inventory.mjs --report`를 실행한다.
4. 공개 범위, 제외 범위, 문서별 밀도, 표기 변이, IPA 사례, 레거시 후보를 결과 그대로 기록한다.
5. 같은 입력에서 재실행해 결과가 재현되는지 확인한다.
6. 파일럿을 마이그레이션한 배치마다 레거시 목록, 예외 상태, 자동 검증 결과, 남은 review 항목을 갱신한다.

최종 감사 문서는 다음을 분명히 구별해야 한다.

- 스크립트가 계수한 사실
- 규약이 정한 구조적 요구
- 사람이 문헌학적으로 승인한 전사
- 아직 review 또는 예외 원장에 남은 항목

## 현재 단계의 제한

인벤토리·검증 도구, 레거시 허용 목록, 예외 원장은 구현되었지만 파일럿 마이그레이션과 전면 이행은 진행 중이다. 그러므로 이 문서는 현재 실측 기준선과 파일럿 목록을 기록할 뿐, 전체 코퍼스의 최종 통과나 레거시 0개를 주장하지 않는다. 파일럿·배치 변경 뒤에는 같은 도구를 재실행해 실측값과 남은 유예를 갱신한다.
