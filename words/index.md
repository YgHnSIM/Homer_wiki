# 어원 사전

호메로스 서사시의 개념·인명이 고대 그리스어에서 현대 영어로 수용되는 실제 경로를 모은 사전입니다. 항목마다 직접 차용, 중간 언어 경유, 학술적 음역을 구분하며, 아래 링크는 작성된 문서만 가리킵니다.
