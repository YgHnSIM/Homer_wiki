# Raw Data Directory (원문 및 원본 소스)

이 디렉토리는 호메로스 위키 구축을 위한 1차 사료, 원문, 번역본, 연구 논문, 참고 자료 등을 보관하는 공간입니다.

## 파일 배치 지침

- **텍스트 소스**: `raw/` 루트에 `.txt`, `.md`, `.pdf` 형식으로 보관합니다.
- **이미지/첨부자료**: `raw/assets/` 폴더에 지도, 영웅 계보도, 고대 그리스 도자기 그림 등의 수록용 이미지를 보관합니다.

## 중요 주의사항

- `AGENTS.md` 지침에 따라, `raw/` 내의 원본 파일은 **LLM이 임의로 편집하거나 수정하지 않는 원본(불변)**으로 유지됩니다.
- 새로운 소스가 추가되면 LLM에게 요약 및 위키 통합(Ingest) 요청을 전달해 주세요.
